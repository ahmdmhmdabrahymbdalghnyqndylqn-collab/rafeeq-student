# رفيق الطالب

واجهة React/Vite إنتاجية متصلة بمشروع Supabase الحالي، كتطبيق ويب قابل للتثبيت لطلاب مصر والأردن.

## المزايا

- تسجيل بالبريد وكلمة المرور، تأكيد البريد، واستعادة كلمة المرور.
- ملف طالب إلزامي يتضمن الدولة ونظام التعليم والصف والمسار.
- خطة دراسية سحابية وحفظ ذري مع كشف تعارض التعديلات بين الأجهزة.
- متابعة الإنجاز ومساعد دراسة يعمل بقواعد محلية بلا API مدفوع.
- مكتبة PDF خاصة بروابط تنزيل قصيرة العمر واقتراحات كتب.
- لوحة مدير لدعوة الطلاب وتعليق الحسابات وحذفها وإدارة الكتب والاقتراحات.
- تطبيق PWA قابل للتثبيت على الهاتف.

## التشغيل

```bash
npm ci
npm run dev
```

يبني `npm run build` نسخة النشر في `dist`.

## Render

يتضمن `render.yaml` إعداد موقع Static مجاني: أمر البناء `npm ci && npm run build` ومجلد النشر `dist`. لا يحتاج التطبيق إلى قاعدة بيانات أو خدمة حوسبة مدفوعة على Render؛ الواجهة تستخدم مشروع Supabase القائم.

## Supabase

الواجهة تحتوي على المفتاح القابل للنشر فقط، وتطبق قاعدة البيانات العزل والصلاحيات عبر RLS. مصدر دالة الإدارة المنشورة محفوظ في `supabase/functions/rafiq-admin` للرجوع إليه.

بعد معرفة رابط النشر النهائي، يجب إدخاله في إعدادات Auth كـSite URL، وإضافة روابط callback لـ`/?account=1` و`/?recovery=1` و`/?account=1&invite=1`. يجب كذلك إعداد SMTP لوصول التأكيد والدعوات إلى أي بريد.

حساب المدير لا يُنشأ تلقائيًا. بعد تسجيل البريد المقصود وتأكيده، تُمنح صلاحية المدير لنفس مستخدم Auth الموثق فقط.
